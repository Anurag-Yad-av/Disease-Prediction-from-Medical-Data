CODEALPHA MACHINE LEARNING INTERNSHIP
TASK 4 — DISEASE PREDICTION FROM MEDICAL DATA

1. Objective
The objective is to apply classification techniques to structured medical data and predict whether a breast tumor is classified as malignant or benign.

2. Dataset
The project uses the Breast Cancer Wisconsin (Diagnostic) dataset available through scikit-learn. It contains numerical measurements associated with digitized images of breast mass cell nuclei.

3. Technologies
Python, Pandas, NumPy, Scikit-learn and Matplotlib.

4. Preprocessing
• 80:20 train-test split with stratification.
• Median imputation for missing numerical values.
• StandardScaler feature normalization.
• Pipeline-based preprocessing to reduce data leakage risk.

5. Models
• Logistic Regression
• Support Vector Machine (SVM)
• Random Forest

6. Evaluation
Accuracy, Precision, Recall, F1-score, ROC-AUC and Confusion Matrix.

7. Results
Exact metric values are generated by running disease_prediction.py and saved in model_results.csv. Confusion matrices are saved as PNG files.

8. Conclusion
This project demonstrates an end-to-end supervised machine-learning workflow for structured medical data: loading, preprocessing, classification, evaluation and model comparison.

9. Limitation
This is an academic project and is not a validated medical diagnostic system. It should not be used for clinical decisions.
